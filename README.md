## Publicar na Netlify

1. Baixe o zip: https://github.com/j2gmidia/nueva-research/archive/refs/heads/main.zip
2. Netlify → **nueva-peptides** → Deploys → arrasta o zip
   **ou** Site configuration → Build & deploy → Link repository → este repo.
3. Build command: vazio. Publish directory: `.`

Dominio: https://nuevaresearch.shop
